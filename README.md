#### 📝 API de Microservicios para Blog
> Plataforma backend para blogs personales desarrollada con Spring Boot y arquitectura de microservicios. Incluye autenticación con JWT, API Gateway, y gestión de usuarios, posts y comentarios.
> **Stack:** `Java` `Spring Boot` `JWT` `API Gateway` `PostgreSQL`

#### 🛒 API de Microservicios para E-commerce
> Plataforma de e-commerce basada en arquitectura de microservicios.
> **Stack:** `Java` `Spring Boot` `Microservicios` `Docker`

#### ☁️ Microservicio de Gestión de Archivos (storage-service)
> Microservicio RESTful tipo Google Drive con operaciones CRUD para archivos, autenticación JWT y sistema de permisos de tres niveles (privado, protegido, público) para compartir recursos de forma granular. Backend en Spring Boot + MinIO, frontend en React, totalmente Dockerizado.
> **Stack:** `Java` `Spring Boot` `React` `MinIO` `PostgreSQL` `Docker`
